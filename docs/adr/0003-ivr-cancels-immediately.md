# The IVR cancels Policies immediately, itself

Cancel Policy is carried out by the IVR with immediate effect, not filed as a request for a human, because there is no staff to review requests. To compensate, only Active Policies can be cancelled and only after an explicit Cancellation Confirmation. Revisit this once agent handoff exists or before real Policyholders call, since provincial auto-insurance rules may require notice or refund handling.
